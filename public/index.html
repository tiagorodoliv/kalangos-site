A Linux desktop that runs light and looks great

KalangOS is a free, open-source operating system built on Debian 13, with its own desktop written in Rust. Made in Brazil, for any computer, old ones included.

Download Source code

● Version 0.1 in testing

Features

Everything you need, nothing in the way

A complete desktop that feels at home from the first minute, on a solid base that has been around for 30 years.

Light on old computers

The desktop draws itself without a graphics card when needed. On a 2 GB machine it uses about 32 MB of memory.

Debian 13 underneath

The stability and security updates of Debian "trixie", with all of its software available.

App store

Thousands of apps from Flathub, installed with one click. No terminal required.

Updates that just work

System and desktop updates arrive from a signed repository and install from Settings, with progress on screen.

Make it yours

Dark, OLED and light themes, six accent colors, icon themes, wallpapers and five dock styles, all changing live.

All in Settings

Wi-Fi, Bluetooth, VPN (WireGuard and OpenVPN), printers, multiple displays, users, power and file sharing with Windows.

Ready for work

LibreOffice opens Word, Excel and PowerPoint files, PDFs open right away and a double-click extracts zip files.

Secure Boot friendly

Boots with Secure Boot on or off, on BIOS or UEFI, and installs alongside Windows with a guided installer.

English and Portuguese

The whole desktop speaks both languages, and you can switch the language and keyboard in Settings.

Download

Try it without installing

Start KalangOS from a USB stick to try it. If you like it, the installer is on the desktop.

KalangOS 0.1 · testing

The first public image is being tested on real hardware. Follow the project on GitHub to know when it is out.

Coming soon Releases on GitHub
  1. Write the image to a USB stick (8 GB or more) with balenaEtcher, Ventoy or Rufus.
  2. Start the computer from the USB stick. The boot menu key is usually F12, F9 or Esc.
  3. Try the desktop, then open “Install KalangOS” from the app menu when you are ready.

System requirements

  • Processor 64-bit (x86-64)
  • Memory 2 GB (4 GB recommended)
  • Disk 20 GB
  • Firmware BIOS or UEFI, Secure Boot on or off
  • Graphics Any; no 3D card required
